\# QGIS Validation



This folder contains records used to verify geospatial outputs in QGIS.



\## Validation checks



1\. Open the generated raster in QGIS.

2\. Confirm that the raster has the expected CRS.

3\. Confirm that the raster covers the selected watershed area.

4\. Check that NoData areas are displayed correctly.

5\. Check NDVI and water-index values.

6\. Compare before and after raster outputs.

7\. Confirm that map previews match the raster outputs.

8\. Record any differences or warnings.



\## Validation record



For each validation run, record:



\- Analysis ID

\- Dataset date

\- Raster name

\- CRS

\- Resolution

\- QGIS version

\- Validation result

\- Observations

\- Validator

\- Date



\## Important



QGIS is used as an independent visual cross-check.



A successful QGIS check does not prove that an observed environmental change was caused by an intervention.
